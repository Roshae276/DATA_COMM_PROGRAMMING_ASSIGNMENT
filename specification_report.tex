\section{1. System Overview \& Deliverables}
The project delivers an end-to-end digital transmission pipeline in \textbf{Python 3.9+} fulfilling all baseline requirements and extra-credit specifications:
\begin{itemize}
    \item \textbf{Data Generator (\texttt{data\_generator.py}):} Generates pseudo-random binary sequences or streams seeded with forced subsequences ($4$ or $8$ consecutive zeros) for scrambling verification.
    \item \textbf{Optimal Palindrome Finder:} Implements \textbf{Manacher's Algorithm} to detect the longest palindromic substring in the bitstream in optimal $\mathcal{O}(N)$ time.
    \item \textbf{Line Encoders (\texttt{line\_coding.py}, \texttt{decoder.py}):} Full implementation of \textbf{NRZ-L}, \textbf{NRZ-I}, \textbf{Manchester} (IEEE 802.3), \textbf{Differential Manchester}, and \textbf{AMI} (with forward encoders and direct decoders).
    \item \textbf{Scrambling Schemes (\texttt{scrambling.py}):} Features \textbf{B8ZS} ($0^8 \to 000VB0VB$) and \textbf{HDB3} ($0^4 \to 000V$ or $B00V$) with DC-balancing pulse logic and corresponding unscramblers.
    \item \textbf{Delta Modulation (\texttt{modulation.py}):} Analog DM encoder and staircase decoder reconstructing continuous input signals using adaptive step size $\Delta$.
    \item \textbf{Extra Credit Image Decoder (\texttt{image\_decoder.py}):} Reconstructs the digital stream by analyzing RGB pixel coordinates and midpoint voltage levels from exported PNG plots rather than direct raw data arrays.
    \item \textbf{Signal Plotter \& CLI (\texttt{signal\_plotter.py}, \texttt{main.py}):} Interactive menu, step waveform rendering, and dual-panel un-scrambled vs.\ scrambled waveform comparisons.
\end{itemize}

% --- 2. Key Engineering Assumptions ---
\section{2. Key Assumptions \& Standards}
\begin{itemize}
    \item \textbf{NRZ-L:} Bit $0 \to +1\text{V}$, Bit $1 \to -1\text{V}$ (standard positive logic).
    \item \textbf{NRZ-I:} Transition at bit boundary for $1$; no transition for $0$. Default starting reference level is $-1\text{V}$.
    \item \textbf{Manchester (IEEE 802.3):} Bit $0 \to [+1, -1]$, Bit $1 \to [-1, +1]$.
    \item \textbf{Diff.\ Manchester:} Transition at start of bit for $0$; no start transition for $1$. Constant mid-bit transition provides clock synchronization.
    \item \textbf{AMI:} Bit $0 \to 0\text{V}$; Bit $1$ pulses alternate polarity between $+1\text{V}$ and $-1\text{V}$.
    \item \textbf{B8ZS Rule:} Pattern $0^8 \to [0, 0, 0, p, -p, 0, -p, p]$, where pulse $p$ matches the polarity of the preceding non-zero pulse.
    \item \textbf{HDB3 Rule:} Pattern $0^4 \to 000V$ if odd number of $1$s occurred since last replacement; $B00V$ if even (pulse $B$ ensures DC balance).
    \item \textbf{Delta Modulation:} Quantization step $\Delta$ and reference are configured at runtime; bit $1 \to +\Delta$, bit $0 \to -\Delta$.
    \item \textbf{Image Decoder:} Plot rendered at 100 DPI with solid blue signal (\texttt{\#0000FF}). Signal level is recovered by vertical center-point column scanning against baseline.
\end{itemize}

\section{4. How to Run the Code}
\begin{enumerate}
    \item \textbf{Clone Repo:} \href{https://github.com/Roshae276/DATA_COMM_PROGRAMMING_ASSIGNMENT}{\texttt{git clone}} (see repository link in header above).
    \item \textbf{Install Dependencies:} \texttt{pip install -r requirements.txt}\\
    \textit{Core libraries:} \href{https://numpy.org/}{NumPy}, \href{https://matplotlib.org/}{Matplotlib}, \href{https://pillow.readthedocs.io/}{Pillow (PIL)}. No MATLAB required.

    \item \textbf{Interactive Workflow:} Select \textbf{1} for Digital Input (Line coding, palindrome detection, AMI scrambling, waveform plot, and extra-credit image decoding) or \textbf{2} for Analog Delta Modulation (staircase signal output).
    \item \textbf{Standalone Image Decoder Test:} \texttt{python image\_decoder.py}
\end{enumerate}
